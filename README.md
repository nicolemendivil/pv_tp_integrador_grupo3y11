## Descripción del Proyecto
El proyecto es un panel de administración web (SPA) desarrollado en React para gestionar una lista de clientes. 
La aplicación permite simular un flujo completo de trabajo: desde el inicio de sesión de los operadores controlando sus accesos mediante un contexto global, hasta la realización de operaciones asincrónicas (como traer el listado, registrar nuevos clientes o eliminarlos) conectándose directamente a una API externa. Además, la interfaz se adapta de manera dinámica mostrando u ocultando opciones según el sector del administrador que haya iniciado sesión (Soporte o Gerencia).
